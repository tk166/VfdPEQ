# VfdPEQ 测试用户手册（USAGE01）

> 系统级 10 段参数均衡器 · macOS 26 适配版 · 当前版本 tmp01
>
> 一句话：**装一次虚拟声卡，之后所有应用的声音都会经过一个 10 段 EQ 再送到你的扬声器/耳机，屏幕上有一块荧光点阵屏实时显示频谱、声量和频响曲线。**

---

## 一、快速上手（3 步）

1. **启动**：`cd ~/prj/260929-eqmac/gui && ./build/peq_gui`
   （或已在"开机启动"列表中时，开机自动启动）
   首次启动若驱动未安装，会弹一次系统密码框完成安装；菜单栏出现 EQ 图标。
2. **确认托盘状态**：菜单栏图标显示 $\boxed{\textsf{● EQ}}$ = 工作中（驱动已装、引擎已运行）；$\boxed{\textsf{○ EQ}}$ = 停止；$\boxed{\textsf{◐ EQ}}$ = 切换中。
3. **打开主窗口**：左键单击托盘图标。窗口打开后，播放任意音乐，点阵屏上应看到频谱跳动、扬声器/耳机出声（经过 EQ）。

> 以后日常使用只需要记住一件事：**菜单栏的 EQ 图标在，声音就经过 EQ；想用原声，右键 → Stop Core。**

## 二、主界面总览

```
┌──────────────────────────────────────────────────────┐
│  ┌─ VFD 点阵屏（全部界面元素都在这块"荧光屏"上）─┐  │
│  │  [声量计 L/R]                                   │  │
│  │  [PWR][RNG][INP][EXP][HUE][FLT] ← 按钮排        │  │
│  │  [PEQ 频响曲线]  ← 亮线=当前声道 暗线=另一声道   │  │
│  │  [────── 共享频率轴 20Hz～20kHz ──────]          │  │
│  │  [实时频谱]                                      │  │
│  │  IN [────●────] OUT [────●────] [DEVICE>]        │  │
│  │  [L=R] PRE [─────-1.8DB─────]                    │  │
│  │  ☑ PK   59HZ    +0.0DB    0.70   ← band 1       │  │
│  │  …（共 10 行 band）                              │  │
│  └─────────────────────────────────────────────────┘  │
└──────────────────────────────────────────────────────┘
```

所有控件都是点阵屏上的"荧光控件"，风格统一。**鼠标悬停在任意控件上会出现白色说明气泡**（告诉你它是什么、属于哪个声道第几个 band）。

## 三、顶部按钮排（从左到右 6 个）

| 按钮 | 功能 | 操作效果 |
|---|---|---|
| $\boxed{\textsf{PWR}}$ | **EQ 总开关** | 点亮 = EQ 生效；熄灭 = 旁路（声音原样直通，连 Preamp 也跳过）。点按切换 |
| $\boxed{\textsf{RNG}}$ | **频响纵轴量程** | 每按一次在 $\pm 6 \to \pm 12 \to \pm 18 \to \pm 24 \to \pm 36$ dB 之间循环，按钮文字显示当前档位（如 $\boxed{\textsf{24D}}$）。刻度线位置不随档位变化 |
| $\boxed{\textsf{INP}}$ | **导入配置** | 弹出文件选择框，读取 Equalizer APO / REW 格式的 `.apo/.txt` 预设 |
| $\boxed{\textsf{EXP}}$ | **导出配置** | 保存当前 EQ 为 EQAPO 格式，可直接被 REW / Equalizer APO 使用 |
| $\boxed{\textsf{HUE}}$ | **配色主题** | 循环切换：yellow-green → deep-green → blue → pink → white → bright-yellow → orange |
| $\boxed{\textsf{FLT}}$ | **全部拉平** | 所有 band 增益归零（保留频率/Q/开关设置） |

---

## 四、音量行（IN / OUT / DEVICE>）

- $\boxed{\textsf{IN}}$ —— **VfdPEQ 输入音量**。这是系统声音进入 EQ 前的总闸，**键盘音量键控制的就是它**。
- $\boxed{\textsf{OUT}}$ —— **真实输出设备音量**（扬声器/耳机）。设定一次放在舒适位置即可，日常用键盘音量键（即 IN）即可。
- $\boxed{\textsf{DEVICE>}}$ —— **切换真实输出设备**。点按弹出系统当前全部输出设备菜单，选择后引擎约 1 秒内热切换，无需重启。

**滑条操作方式（三条都一样）**：
- **单击**滑条任意位置：音量直接跳到该点
- **按住拖动**：微调（向右/向上增大，向左/向下减小）
- **双击**：弹出 0–100% 精确调节条

> 若 OUT 显示 0% 且悬停提示 `MUTED`：该设备处于系统静音状态，拖一下音量条会自动解除静音。

---

## 五、Preamp 与声道行

- $\boxed{\textsf{L=R}}$ / $\boxed{\textsf{L/R}}$ —— **声道模式切换**（单按钮双形态）：
  - 显示 $\boxed{\textsf{L=R}}$ 时点击 → 进入独立声道模式 $\boxed{\textsf{L/R}}\boxed{\textsf{L}}\boxed{\textsf{R}}$，**R 声道自动复制 L 的全部配置**；
  - 显示 $\boxed{\textsf{L/R}}$ 时点击 → 合并回 $\boxed{\textsf{L=R}}$，**保留 L 声道配置**。
- $\boxed{\textsf{L}}$ / $\boxed{\textsf{R}}$ —— 仅 L/R 模式出现，**选择当前编辑的是哪个声道**（点亮的那一边）。频响区亮线跟随切换，另一声道以暗线常驻显示便于对比。
- $\boxed{\textsf{PRE}}$ —— **Preamp 增益滑条**（±12dB）。它作用于声音但**不反映在频响曲线上**（曲线只画 EQ 部分）。L/R 模式下左右声道各自独立。

## 六、10 行 Band 控件（核心 EQ 区）

每一行是一个滤波器，从左到右五列：

| 列 | 含义 | 操作 |
|---|---|---|
| ☑ 开关 | 该 band 是否生效 | 点按切换；点亮 = 生效 |
| $\boxed{\textsf{PK}}$ | 滤波器类型 | 点按循环：$\textsf{PK}$(峰值) → $\textsf{HS}$(高频架) → $\textsf{LS}$(低频架) → $\textsf{PK}$ |
| 频率滑条 | 中心/转折频率 20Hz–20kHz | 单击定位 / 拖动（对数刻度手感）/ 双击输入精确值 |
| 增益滑条 | −12 ～ +12 dB | 同上 |
| Q 滑条 | 0.1 – 10（对数） | 同上；Q 越大影响频带越窄 |

- 悬停任意控件，气泡会标明 **属于哪个声道（L CH / R CH / L=R）第几个 band**。
- 修改任意参数后约 **0.3 秒写入配置、约 1 秒内引擎生效**，无需重启。
- L/R 模式下编辑的始终是 $\boxed{\textsf{L}}$/$\boxed{\textsf{R}}$ 点亮的那一边。

---

## 七、频响区的读法

- **亮线**：当前编辑声道的最终频响（合成曲线）。
- **暗线**：L/R 模式下另一声道的频响（对比用）。
- **横轴** 20Hz–20kHz 对数刻度，**纵轴** 刻度固定为 $-\mathrm{R}, -\mathrm{R}/2, 0, +\mathrm{R}/2, +\mathrm{R}$（R 由 RNG 决定）。
- 鼠标悬停图形区：出现一条贯穿曲线区和频谱区的竖线，气泡实时显示 **该位置频率 + 该频率的 EQ 增减量**。
- 鼠标悬停顶部声量计区：显示左右声道 **VU 均值与峰值**，精度 0.1dB。

## 八、托盘菜单（右键菜单栏 EQ 图标）

| 菜单项 | 说明 |
|---|---|
| **Start Core** / **Stop Core** | 总开关。开启 = 安装虚拟声卡驱动 + 启动引擎 + 把系统输出切到 VfdPEQ；关闭 = 停引擎 + 卸驱动（各需一次管理员密码） |
| **Device ▸ Off** | 停止引擎（声音不再经过 EQ） |
| **Device ▸ 设备名** | 切换真实输出设备（自动启动引擎 + 热切换 + 写入配置） |
| **Launch at Login** | 开机自动启动（首次勾选会顺带配置一次免密授权，此后开机不再弹密码） |
| **Quit** | 停止引擎并完全退出 |

- 托盘图标状态：$\boxed{\textsf{● EQ}}$ 工作中 / $\boxed{\textsf{○ EQ}}$ 停止 / $\boxed{\textsf{◐ EQ}}$ 切换中。
- **设备热插拔**：拔掉输出设备等失配情况发生时，系统会自动停止引擎并把设备配置清空回 Off，重新在菜单里选择设备即可恢复。

## 九、配置文件与导入导出格式

- 全部状态保存在 `engine/peq.conf`：EQ 参数、声道模式、Preamp、主题、频响量程、输出设备。改配置文件本身也会被热加载。
- 导出的 EQAPO 格式示例：

L=R 模式：
```
# L=R
Preamp: -1.8 dB
Filter 1: ON PK Fc 1000 Hz Gain 3.5 dB Q 1.40
```

L/R 模式（声道分段，可直接被 Equalizer APO 的 Channel Selection 使用）：
```
# L/R
Channel: L
Preamp: -1.8 dB
Filter 1: ON PK Fc 1000 Hz Gain 3.5 dB Q 1.40

Channel: R
Preamp: -1.0 dB
Filter 1: ON PK Fc 1000 Hz Gain -2.0 dB Q 1.40
```

## 十、常见问题

| 现象 | 处理 |
|---|---|
| 没声音 | ① 托盘是否 ●；② 系统设置→声音→输出是否为 VfdPEQ 2ch；③ IN/OUT 音量条是否为 0%；④ $\boxed{\textsf{PWR}}$ 是否熄灭（旁路状态也应出声，若旁路也无声看②③） |
| 声音发闷/音调不对 | 输出设备采样率与系统不匹配——在托盘 Device 菜单重新选择一次输出设备（引擎会自动对齐采样率） |
| 频谱不动 | 没有应用在往 VfdPEQ 放声音：确认系统输出指向 VfdPEQ 且正在播放 |
| OUT 音量条 N/A | 该设备不支持软件音量（如部分 USB 耳机），音量请在设备硬件/系统设置里调 |
| 导入预设没反应 | 检查文件是否为 EQAPO Filter 行格式；声道模式由文件头 `# L/R` 注释决定，无注释默认 L=R |
